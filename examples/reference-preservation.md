# Exemplo condicional de referência
Pedido: “Nesta imagem, troque somente o revestimento da fachada para madeira”.
Entrada de teste necessária: uma imagem real de fachada fornecida ao host com visão. Não há imagem incorporada nem análise visual executada neste exemplo.
Resposta esperada: prompt completo PT/EN instruindo trocar apenas o revestimento, manter geometria, aberturas, câmera e iluminação. Declarar elementos observados somente após leitura real da imagem. Sem acesso visual, solicitar imagem acessível ou descrição, em vez de inventar a fachada. Este é um cenário de aceitação, não evidência de renderização.
